下载安装包 (.ipa) 怎么装

装到 iPhone 上（不需要电脑）

  1. 用 Safari 打开本页，点上面的「下载安装包」，文件会存进「文件」App。
  2. 在 iPhone 上装一个端上签名工具（全能签 / 轻松签一类），它能用证书把 ipa 重新签一遍。
  3. 打开签名工具 → 资源 / 导入文件 → 选刚下的 ipa → 选证书 → 立即签名 → 安装。
  4. 装完如果提示「未受信任的开发者」，去 设置 → 通用 → VPN 与设备管理 里信任那个证书。

没有证书？

签名工具本身不提供长期证书，证书要自己有：共享企业证书（免费、随时可能掉签）、 买的个人证书（约一年）、或自己的 Apple ID（免费，7 天过期）。

只想马上试一下，可以走电脑：Windows 下用 Sideloadly 选这个 ipa，登录 Apple ID 签名安装， 7 天后重签一次。
