下载安装包 (.ipa) 怎么装

用全能签装（照原厂做法，不需要电脑）

  1. 先装全能签本体。同一台 iPhone 上用 Safari 打开 https://udid.nuosike.cn/sign/（官网，全称无锡诺思客，ICP 苏ICP备19018114号）， 点页面上的【安装全能签】；若它要你填兑换码，留空即可（那是给已有证书的人用的）。 装完在 设置 → 通用 → VPN 与设备管理 里信任那个企业证书。
  2. 拿到证书。全能签只是签名工具，真正决定能不能装、能装多久的是证书： 全能签官方卖的 P12 约 ¥58 起（340 天，档位差别只在补签次数）， 第三方卡密约 ¥18–49（质保 40–330 天）。免费共享证书也能签，但随时掉签。
  3. 导入证书。打开全能签 → 设置 → 导入文件 → 先选 .p12（输密码）→ 再选 .mobileprovision → 到底部「证书」页确认状态是有效。
  4. 导入本页的 ipa。回到本页点「下载安装包」，文件存进「文件」App； 再回全能签 → 设置 → 导入文件 → 选那个 ipa。
  5. 签名并安装。全能签 → 资源 → App → 点这个 ipa → 签名 → 选刚导入的证书 → 立即签名 → 完成后点安装。
  6. 打开 App。若提示「未受信任的开发者」，去 设置 → 通用 → VPN 与设备管理 信任；iOS 16 及以上还要在 设置 → 隐私与安全性 → 开发者模式 打开开关并重启一次。

两个容易卡住的地方

1. 证书的 App ID 对不上。如果买的证书绑的是固定 App ID，签名时会报 Bundle ID 不匹配。 全能签签名页里可以直接把 Bundle ID 改成证书支持的那个（比如后面加几个字母），改完照常签。

2. 掉签。共享证书被苹果封掉时，用它的 App 全部打不开。恢复办法是换一张证书重签一次， 数据不会丢（全能签重签保留原 App 数据）。

不想买证书

走电脑：Windows 装 Sideloadly，选本页的 ipa，登录自己的 Apple ID 签名安装。 免费、确定能用，代价是每 7 天要连一次电脑重签。

这是第三方客户端，与 WhatsApp Inc. 无关。只在自用范围内使用，别拿去冒充官方版本分发。 签名工具只从官网下，别把 Apple ID 密码交给任何第三方。
