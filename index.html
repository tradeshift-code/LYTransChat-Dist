下载安装包 (.ipa) 怎么装
先准备一根「能传数据」的数据线。 很多便宜的线只接了电源，插上只能充电、电脑认不到手机 —— 那种不行。 iPhone 15 / 16 是 USB-C，iPhone 14 及更早是 Lightning。 线只需要用一次：配对成功后打开 Wi-Fi 续签，以后不用再插。

装到 iPhone 上（第一次要电脑，之后可无线）

  1. 电脑上装 Sideloadly。Windows 打开 https://sideloadly.io/SideloadlySetup64.exe （137.5 MB）。装完不会自动启动，到开始菜单里找 Sideloadly。
    注意 它要求装网页版 iTunes / iCloud，不要用 Microsoft Store 版； 本机若已有 Apple Mobile Device Service 就够，不必另装 iTunes。
  2. 插线并信任。数据线连电脑 → iPhone 解锁 → 弹出「要信任此电脑吗」点 信任 → 输入锁屏密码。电脑上打开 Sideloadly，左上角设备列表应出现你的 iPhone 名字。
  3. 装入 ipa。点上面的「下载安装包」或用电脑上已有的文件，把它拖进 Sideloadly 窗口。
  4. 签 Apple ID。Apple ID 栏填你自己的账号 → 点 Start → 输密码。 开了双重认证的话，手机会弹 6 位验证码，填进 Sideloadly 的弹窗。
  5. 信任 + 开发者模式。设置 → 通用 → VPN 与设备管理 → 点你的 Apple ID → 信任； 设置 → 隐私与安全性 → 开发者模式 打开 → 重启 → 确认。 iOS 16 以上不开，点了就闪退。
  6. （强烈建议）打开 Wi-Fi 续签。在 Sideloadly 里勾上自动续签，再到 iTunes 里 设备 → 摘要 → 选项 → 勾「通过 Wi-Fi 与此 iPhone 同步」→ 同步。 之后电脑与手机在同一 Wi-Fi 下，守护进程会在到期前自己重签，不用再插线。
    记下来 续签必须用同一个 Apple ID 与同一个 Bundle ID （com.lytranschat.app），改了会当成另一个 App，聊天记录与登录态全清。

常见报错

找不到设备：换一根确定能传数据的线，手机保持解锁，点过「信任」；

Maximum number of installed apps：免费账号 3 个自签名额满了，删掉一个别的自签 App；

Maximum App ID limit reached：7 天内建了 10 个 App ID，等几天或换账号；

Untrusted Developer：没在「VPN 与设备管理」里信任，或开发者模式没开。

没有数据线怎么办（全能签，要自备证书）

全能签能在手机上直接签，不用电脑，但它只接受 p12 证书（没有 Apple ID 登录）。 官方只卖证书（¥58 起 / 约 340 天），第三方卡密 ¥18 起； 免费共享证书全来自第三方站点，其中不少是被苹果撤销的证书，领用前要求装「描述文件」， 装错可能导致设备重置。掉签随时发生，权限也常被裁剪。

原厂官网「移动端 · 苹果」给三条：① TestFlight（主推，公开邀请，无需邀请码）； ② 把 Apple ID 地区改到海外后 App Store 搜「WATransChat」下载 （已上架美区，id 6761809886，当前 v2.90，大陆 ID 搜不到）； ③ 全能签 + 付费证书，原厂原文写着「需要付费购买证书」。 三条都依赖 $99 开发者账号或付费证书 —— 原厂自己走的是前两条。
