下载安装包 (.ipa) 怎么装
关于「免费共享证书」，实话： 全能签官方只卖证书，不提供免费证书。市面上流传的免费企业证书全部来自第三方站点， 其中相当一部分是已被苹果撤销的证书——领的时候要你先装一个「描述文件 / 配置描述」， 装错可能导致设备需要重置才能再装应用。 掉签也是随时的事：证书被封的那一刻，用它签的 App 全部打不开，而且不在你能控制的时间内。

装到 iPhone 上（全程手机，不用电脑）

  1. 装全能签本体。Safari 打开 https://udid.nuosike.cn/sign/（官网）， 点【安装全能签】。它自己是企业签的，装完必须去 设置 → 通用 → VPN 与设备管理 信任它，否则打不开。
  2. 准备证书。两条路，二选一：
    方式成本寿命
    买 P12 兑换码（官方 ¥58 起 / 第三方卡密 ¥18 起）¥18–58约 340 天
    第三方免费共享企业证书0随时掉签
    买的话：全能签 → 设置 → 兑换证书，填兑换码，生成后到「证书」页确认有效。 用共享证书的话：先确认来源可信，只导入 .p12（需要密码）和 .mobileprovision，不要装任何来路不明的「配置描述文件」。
  3. 先取 UDID。全能签 → 底部「设置」→ 获取设备 UDID → 按提示到设置里装描述文件 → 装完会自动跳回，提示 UDID 获取成功。企业证书签名有时需要它。
  4. 导入本页的 ipa。点上面的「下载安装包」存进「文件」App； 回到全能签 → 设置 → 导入文件 → 选那个 ipa。 （也可以直接点 ipa 文件，弹「用全能签打开」更快。）
  5. 签名并安装。全能签 → 底部「资源」→ 点这个 ipa → 签名 → 选证书 → 立即签名 → 完成后点安装。
    记下来 签名页会显示最终的 Bundle ID：证书是纯通配符 * 时可以保留 com.lytranschat.app；如果是 com.某企业.* 这类前缀证书， 工具会要求改成该前缀下的名字。无论改成什么，续签时必须用同一个， 否则系统会当成另一个 App，聊天记录与登录态全部清空。
  6. 信任 + 开发者模式。设置 → 通用 → VPN 与设备管理 信任新证书； 设置 → 隐私与安全性 → 开发者模式 打开 → 重启 → 确认。 iOS 16 以上不开，点了就闪退。

这条路的三个已知代价

1. 掉签不可预期。共享证书被封时 App 直接打不开。数据不会丢，换证书重签一次就能恢复， 但时间是证书拥有者说了算，不是你。

2. 企业证书权限不完整。免费/共享证书常常没开某些能力（例如后台处理、推送）。 我们的 App 里「锁屏也在后台收消息」正是靠这个 —— 这条可能签不出来， 装完要实测后台能否存活。

3. 来源风险。第三方证书站点可能要求安装描述文件，等于把设备的部分控制权交出去。 只从认识的人或长期运营的渠道拿，别在陌生群里点链接。

如果这条走不通

换成 Sideloadly + 自己的 Apple ID：Windows 电脑装一次，登录 Apple ID 签名， 免费、7 天一次、时间可预期，证书是你自己的，没有第三方经手。 代价是要连电脑。

原厂是怎么分发的（核实记录）

原厂官网「移动端 · 苹果」给三条：① TestFlight（主推，公开邀请，无需邀请码）； ② 把 Apple ID 地区改到海外后 App Store 搜「WATransChat」下载 （已上架美区，id 6761809886，当前 v2.90，大陆 ID 搜不到）； ③ 全能签 + 付费证书，原厂原文写着「需要付费购买证书」。 三条都依赖 $99 开发者账号或付费证书 —— 原厂自己走的是前两条，全能签是给用户的兜底。

这是第三方客户端，与 WhatsApp Inc. 无关。只在自用范围内使用，别拿去冒充官方版本分发。 任何「配置描述文件」都不要随手装；Apple ID 密码不要交给任何网页或客服。
