iPhone 安装页 · 用自己的 Apple ID，零成本

下载安装包 (.ipa) 怎么装
先说清一件事：全能签不能用自己的 Apple ID。 它要的是 p12 证书 + .mobileprovision 描述文件 （官方帮助页五类教程全是「证书兑换与导入」，没有 Apple ID 登录入口）。 原厂官网自己也是这么写的：「使用第三方签名工具（如全能签）进行安装。需要付费购买证书。」 所以要用手上的 Apple ID，就得借用一次 Windows 电脑，装完以后不再需要。

装到 iPhone（Windows + 数据线，约 10 分钟）

  1. 先在本页把 ipa 下下来。点上面的「下载安装包」，文件存进「文件」App， 或者留在电脑上（后面直接拖进签名工具，更省事）。
  2. 电脑上装 Sideloadly。官网 sideloadly.io，Windows 版，安装包几十 MB。 它默认装到 %LOCALAPPDATA%，可以指定到 D 盘。 本机需要「Apple 移动设备驱动」——这台电脑已经有 Apple Mobile Device Support，通常不用再装。
  3. 连手机。数据线插上，iPhone 弹「是否信任此电脑」→ 信任 → 输锁屏密码。 Sideloadly 左上角会显示设备名，说明认到了。
  4. 签名并安装。把 ipa 拖进 Sideloadly 的 IPA 框； Apple ID 填你的邮箱；点 Start。中途会要 Apple ID 密码 （开了双重认证会再要一次验证码，或者要「App 专用密码」—— 去 appleid.apple.com → 登录与安全 → App 专用密码 生成一串填进去）。
    建议 自签有账号风控风险，有条件就注册一个只用来自签的小号， 别拿主力 Apple ID 上。
  5. 信任 + 开发者模式。设置 → 通用 → VPN 与设备管理 → 信任你的 Apple ID； 再到 设置 → 隐私与安全性 → 开发者模式 → 打开 → 手机重启 → 重启后确认「打开」。 iOS 16 以上不开这一步，App 点开就闪退。
  6. 打开 App。应该看到「内核已就绪」。长按版本号能看到更新弹窗， 三个按钮里「前往全能签」只是把这个 ipa 的直链复制到剪贴板（原厂行为如此）。

三个硬限制（不是 App 的问题）

1. 7 天过期。从签完那一刻算 7×24 小时，之后 App 一点就闪退 —— 不是坏了，是签名过期了。 重新用 Sideloadly 走一遍上面第 4–6 步即可，覆盖安装，聊天记录不丢（前提是 Bundle ID 不变， Sideloadly 默认不改）。

2. 一台设备同时最多 3 个自签 App。装第 4 个时 iOS 会让你先删一个。

3. 免费账号签不出推送 / 内购 / iCloud / Apple Pay。 我们没用推送（原厂也没用，靠后台模式保活），内购改走激活码，所以不受影响。 但后台保活能做到什么程度，得装上去实测 —— 这是 iOS 和安卓差别最大的地方。

不想每 7 天连电脑

Sideloadly 支持 Wi-Fi 续签：手机和电脑在同一 Wi-Fi 下，Sideloadly 开着就能自动重签 （需要它的小守护进程常驻，Win 上会随开机启动）。
另一条路是 AltStore（Windows 装 AltServer，手机装 AltStore），同样靠同 Wi-Fi 自动续签， 但要额外装 iTunes 和 iCloud 的桌面版。
想彻底不续签就买 p12 证书（约 ¥18–58 / 340 天），那时可以改走全能签， 全程在手机上，流程见下方折叠段。

买了 p12 证书的话（全能签流程）
  1. Safari 打开 https://udid.nuosike.cn/sign/，点【安装全能签】， 装完到 设置 → 通用 → VPN 与设备管理 信任它的企业证书。
  2. 打开全能签 → 底部「设置」→ 获取 UDID（会跳设置装描述文件，按提示装完自动回跳）。
  3. 设置 → 导入文件 → 选 .p12 → 输密码；再选 .mobileprovision。 到「证书」页确认状态是有效。
  4. 设置 → 导入文件 → 选本页的 ipa。到「资源」→ 点这个 ipa → 签名 → 选证书 → 立即签名 → 完成后点安装。
  5. 安装页会要求 Bundle ID 与证书匹配，改了要记住，以后续签用同一个。
原厂是怎么分发的（核实记录）

原厂官网「移动端 · 苹果」给的是三条：① TestFlight（主推，公开邀请链接，无需邀请码）； ② 把 Apple ID 地区改到海外后在 App Store 搜「WATransChat」下载 （已上架美区，id 6761809886，当前 v2.90，大陆 ID 搜不到）； ③ 全能签 + 付费证书，原厂原文写着「需要付费购买证书」。 三条都依赖 $99 开发者账号或付费证书，没有一条是「用自己的 Apple ID 自签」。
本页走的是第四条 —— 只自己用时的零成本做法，也正是原厂开发期给自己手机装包的方式。
